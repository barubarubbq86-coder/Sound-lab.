# おとの じっけんしつ：GitHub Pages版 v4

## 公開する
1. ZIPを展開します。
2. GitHubのリポジトリで Add file → Upload files を開きます。
3. index.html、app.js、style.css、pwa.js、sw.js、manifest.webmanifest、iconsフォルダなど、展開した中身をアップロードします。ZIPそのものはアップロードしません。index.htmlがリポジトリの一番上にあるようにしてください。
4. Settings → Pages → Deploy from a branch → main / (root) → Save。
5. 表示されたHTTPSの公開URLをChromeで開きます。

## インストール
Android：Chromeの︙→「ホーム画面に追加」→「インストール」。画面下の「インストール」内のボタンが出る場合は、そこからも可能です。
iPhone：Safariの共有→「ホーム画面に追加」。
表示文言やインストール項目はブラウザによって異なります。HTMLファイルを直接開いただけではインストールできません。

## 使い方
画面上のソフトキーで入力します。スマホの文字キーボードは使いません。
「ことばを まぜる」では、IPA・ピンイン・ひらがなを一つの欄に混ぜて入力できます。IPA欄の言語は、その後に押すキーに適用されます。
声の高さ・速さを変更できます。履歴は同じブラウザ内に保存します。録音機能はありません。

## 音声が出ないとき
初期設定は、ブラウザが端末内で処理すると申告した音声のみです。その言語の音声がないと再生を止めます。
端末の音声読み上げ設定で必要な言語の音声を追加し、ページを開き直してください。
「ほかの声も使う」を有効にすると再生できる場合がありますが、文字が音声サービスへ送られる可能性があります。この許可は保存しません。
IPAは綴りへの近似変換、中国語ピンインは一部の例の変換です。任意の発音記号や声調を厳密に再現するアプリではありません。

## オフラインと更新
一度オンラインで読み込み、オフライン保存が完了すれば、画面をオフラインで開けます。音声は端末・音声エンジンに依存します。
更新時は同じファイルを上書きし、sw.jsのCACHEの末尾をv5などへ変更してください。
オンラインで一度開いた後、アプリと同じページのタブをすべて閉じ、再度開くと更新されます。
ブラウザのデータ削除で履歴とキャッシュは消えます。以前のHTMLファイル版の履歴は公開URLへ自動移行しません。

## 安全性確認
- 入力・履歴のアップロード、広告、アクセス解析、外部ライブラリ、外部フォント：なし。
- マイク、カメラ、位置情報、通知の要求：なし。
- 通信は公開元のアプリファイルの取得・更新。Service Workerはこのアプリの固定ファイルだけを保存します。
- Service Workerのキャッシュ削除対象は、このアプリの公開パス専用のキャッシュだけです。
- 入力と履歴は文字として表示し、入力をHTMLとして実行しません。
- 初期設定の音声はlocalService=trueのもののみ。ブラウザ・OSの申告や内部通信までは独立検証できません。
- GitHub Pagesではアクセス時のIPアドレスがセキュリティ目的で保存されます。
- 同じGitHub Pagesドメインの他アプリとはブラウザの保存領域のオリジンが共通です。自分で信頼するコードだけを公開してください。

確認はコード・パッケージを対象とします。公開後のAndroid実機でのインストールと音声は別途確認が必要です。
